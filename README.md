# Vertex Buddy Pro — Intermediate Counselling App

A student counselling web app that helps Class 12 / Intermediate students explore branches and career opportunities after their board exams.

## Features

- **Board Selection** — CBSE, State Board (AP/TS), ICSE/ISC
- **Branch / Stream Explorer**
  - CBSE: Science (PCM, PCB, PCMB), Commerce, Humanities/Arts
  - State Board: MPC, BiPC, CEC, HEC, MEC, Vocational
  - ICSE: Science, Commerce, Humanities
- **Detailed Opportunities Page** per branch showing:
  - Career options with descriptions
  - Recommended courses
  - Key entrance exams
  - Top colleges & institutes

## Tech Stack

- React 19 + Vite 8
- Tailwind CSS v4

## Getting Started

```bash
npm install
npm run dev        # Development server on http://localhost:5173
npm run build      # Production build
npm run lint       # ESLint check
```
